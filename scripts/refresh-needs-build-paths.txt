# Paths whose change in a weekly-refresh commit means the commit must NOT carry
# "[vercel skip]" -- i.e. it needs a real Vercel build to surface on the site.
#
# Read by BOTH .github/workflows/civic-data-refresh.yml and
# mac-mini-jobs/metro-mini-refresh.sh. One list, two consumers, so they cannot
# drift apart the way the two jobs.toml copies did on 2026-08-06 and the way
# run-deploy-watch.sh's hardcoded copy of the build-path list silently did.
#
# THE DISTINCTION THIS ENCODES
# Most refreshed data under public/data is ISR-read from GitHub raw at request
# time (the Zone Zero Cup, the ESPN snapshots, the football live bundles, the
# season sims, the business files). Those surface with no deploy, so their
# commits correctly ride "[vercel skip]".
#
# These paths are different: `lib/` reads them with readFileSync at BUILD time,
# so a refreshed file sits in the repo doing nothing until some unrelated commit
# happens to trigger a build. That is not a refresh strategy, it is luck.
#
# WHY THIS FILE EXISTS (2026-08-11)
# scripts/vercel-ignore.sh rule 1 skips on "[vercel skip]" in the subject line
# BEFORE it ever runs the build-relevant path test, and run-deploy-watch.sh
# likewise skips past any "[vercel skip]" subject when choosing its TARGET. So a
# tagged commit that changes a build-time-read file is invisible to both the
# guard and the healer. Both consumers previously tested exactly ONE path
# (public/data/leaders/_changes.json) and hardcoded it inline; valuations had the
# same build-time-read shape and was missed.
#
# BEFORE ADDING A PATH HERE, CHECK THE READER.
# If the corresponding lib/ module uses readFileSync at build time, it belongs
# here. If it uses the GH-raw ISR reader (see lib/seasonSim.ts or
# lib/zoneZeroCup.ts for the pattern), it does NOT -- adding it would buy a
# weekly production build for nothing.
#
# One path per line. Blank lines and lines starting with # are ignored.

# lib/leaders reads the per-country history at build time; a leadership change
# rewrites leaders/<slug>.json, which country pages bake in.
public/data/leaders/_changes.json

# lib/valuations.ts -> readFileSync, no ISR. Feeds /sports/valuations and the
# ValuationChip on every team page.
public/data/valuations

# lib/teamOwners.ts -> readFileSync, no ISR. Feeds /sports/owners and the Owner
# column on /sports/valuations.
public/data/owners
